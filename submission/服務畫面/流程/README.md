# 真機逐步截圖（Galaxy S26 Ultra，APK 內建離線版，2026-11-08）

每個資料夾是一個完整案例：從小幫手把人送到服務頁開始，每做一個動作截一張圖，直到流程結束（送出／繳費完成／看到結果）。
動作都是「跟著亮框走」：點亮框、在亮框的欄位打字、Enter 換下一欄；只有原生選單（院區、科別）和日曆是在系統視窗裡點。

| # | 案例 | 動作 | 結束畫面 |
|---|---|---|---|
| 01 | 繳水費 | 點水號欄 → 打 10 碼（自動下一步）→ 查詢 → 全部繳清 → 前往繳費 → 信用卡 → 是 | 繳費完成 |
| 02 | 繳停車費 | 汽車 → 車牌欄 → 打 ABC1234 + Enter → 查詢 → 全部繳清 → 前往繳費 → 信用卡 → 是 | 繳費完成 |
| 03 | 繳學雜費 | 繳費編號欄 → 打 8 碼 + Enter → 查詢 → 全部繳清 → 前往繳費 → 信用卡 → 是 | 繳費完成 |
| 04 | 繳聯醫醫療費 | 證件號碼 + Enter → 出生日期（日曆選 15）→ 院區（原生選單）→ 查詢 → 全部繳清 → 前往繳費 → 信用卡 → 是 | 繳費完成 |
| 05 | 找廁所 | 關掉定位提示 → 點開清單 → 點「飲水機、公廁…」→ 點「公廁」→ 點標記 | 地址卡 |
| 06 | 圖書借閱 | 關鍵字搜尋 → 搜尋欄 → 打書名 → 放大鏡 | 搜尋結果 |
| 07 | 有話要說 | 更多項目 → 點「垃圾、噪音…」→ 點項目 → 地點 + Enter → 主旨 + Enter → 描述 → 同意 → 送出 | 案件已受理 |
| 08 | 聯醫掛號 | 院區（原生選單）→ 科別（原生選單）→ 點時段 → 確認掛號 | 掛號完成 |
| 09 | 報水表度數 | 水號 10 碼（自動下一步）→ 度數 → 送出 | 送出完成 |
| 10 | 訂閱通知 | 點「停車費通知」→ 訂閱 | 已訂閱 |

重現方式：`sh scripts/phone-case.sh <案例名> <guide id> <起始網址> '<params>' <動作...>`（見 scripts/phone-case.sh）。
